# Phím tắt

Bảng này liệt kê phím tắt **mặc định** của BlueDoc, BlueSheet và BlueSlide. Trên máy Mac, `Ctrl` là phím `Cmd`.

Bạn có thể đổi phím tắt của bất kỳ lệnh nào ở **Tệp › Tùy chọn › Tùy biến phím tắt…**
([README.md](README.md#38-tuỳ-biến-ribbon-thanh-truy-cập-nhanh-và-phím-tắt)). Phím tắt hiện tại của mỗi lệnh cũng
hiện trong chú giải khi bạn rê chuột lên nút trên ribbon.

- [Dùng chung](#dùng-chung)
- [BlueDoc](#bluedoc)
- [BlueSheet](#bluesheet)

## Dùng chung

### Giao diện

| Phím                 | Tác dụng                                                         |
| -------------------- | ---------------------------------------------------------------- |
| `Alt+Q`              | Mở ô **Tìm lệnh**                                                |
| `Alt` (nhấn rồi thả) | Hiện chữ gợi ý phím trên ribbon; gõ chữ của tab rồi chữ của lệnh |
| `F10`                | Như `Alt`: hiện chữ gợi ý phím                                   |
| `Ctrl+F1`            | **Thu gọn ribbon** / **Mở rộng ribbon**                          |
| `Shift+F10`          | Mở menu chuột phải tại vị trí đang chọn                          |
| `F6`                 | Chuyển qua lại giữa tài liệu và các ngăn tác vụ                  |
| `Esc`                | Đóng hộp thoại, menu, ngăn đang mở; thôi thao tác đang làm       |

Khi chữ gợi ý phím đang hiện: phím `F` mở **Tệp**; `1`, `2`, `3` là **Đậm**, **Nghiêng**, **Gạch chân**. Các chữ
khác lấy từ tên tab và tên lệnh nên thay đổi theo ngôn ngữ giao diện.

### Di chuyển con trỏ và chọn văn bản

| Phím                     | Tác dụng                                                                         |
| ------------------------ | -------------------------------------------------------------------------------- |
| `←` `→` `↑` `↓`          | Di chuyển một ký tự / một dòng                                                   |
| `Ctrl+←` / `Ctrl+→`      | Di chuyển một từ                                                                 |
| `Home` / `End`           | Về đầu dòng / cuối dòng                                                          |
| `Ctrl+Home` / `Ctrl+End` | Về đầu văn bản / cuối văn bản                                                    |
| `PageUp` / `PageDown`    | Lên / xuống một trang màn hình                                                   |
| `Shift` + các phím trên  | Mở rộng vùng chọn                                                                |
| `Backspace` / `Delete`   | Xoá ký tự trước / sau con trỏ                                                    |
| `Tab` / `Shift+Tab`      | Trong bảng: sang ô sau / ô trước (ở ô cuối: thêm hàng mới); ngoài bảng: chèn tab |

### Di chuyển và nhập liệu

| Phím                         | Tác dụng                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------- |
| `←` `→` `↑` `↓`              | Sang ô bên cạnh                                                              |
| `Ctrl` + mũi tên             | Nhảy 50 ô theo hướng mũi tên                                                 |
| `Shift` + mũi tên            | Mở rộng vùng chọn                                                            |
| `PageUp` / `PageDown`        | Lên / xuống một màn hình                                                     |
| `Enter` / `Shift+Enter`      | Xuống ô dưới / lên ô trên (trong vùng chọn nhiều ô: sang ô kế tiếp của vùng) |
| `Tab` / `Shift+Tab`          | Sang ô phải / ô trái                                                         |
| `F2`                         | Sửa ô đang chọn                                                              |
| `Backspace`                  | Xoá nội dung ô và bắt đầu gõ                                                 |
| `Esc`                        | Huỷ nội dung đang gõ; thôi sao chép định dạng                                |
| `F4` (khi đang gõ công thức) | Đổi kiểu tham chiếu: `B2` → `$B$2` → `B$2` → `$B2`                           |
| `Alt+↓`                      | Mở danh sách chọn của ô có xác thực kiểu **Danh sách**                       |
| `Space`                      | Đánh dấu / bỏ đánh dấu ô đánh dấu                                            |
| `Ctrl+Enter`                 | Gửi bình luận đang gõ trong ngăn **Bình luận**                               |
