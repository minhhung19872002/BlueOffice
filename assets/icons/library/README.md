# BlueOffice icon library

Insertable icons of the "Biểu tượng" (Icons) command of BlueDoc, BlueSheet and BlueSlide
(CORE-ICON-001).

- **Origin and licence:** original work of the BlueOffice project (Bluestar). Every icon was
  drawn by hand for this library on a 24 × 24 grid; nothing is copied or traced from a
  third-party or commercial icon set. No third-party licence applies.
- **Do not edit the files here by hand.** They are generated by
  `node scripts/gen-icon-library.mjs`, which holds the drawings, names and keywords and also
  writes `packages/ui/src/iconLibrary/data.json` (the chunk the dialog loads on first use).
  Add or change an icon in that script, run it, and commit the three outputs together.
- **`manifest.json`:** `categories` (id, Vietnamese and English name) and `icons` (id,
  category, file, Vietnamese and English name, keywords — the Vietnamese keywords are listed
  with and without diacritics so that "mui ten" finds "Mũi tên").
- **Drawing rules** (checked by `packages/ui/test/iconLibrary.test.tsx`): `viewBox="0 0 24 24"`,
  only `path`, `rect`, `circle` and `ellipse` — what the BlueOffice SVG reader
  (`crates/bo-drawingml/src/svg.rs`) converts to shapes — with an explicit `fill` and `stroke`
  on every element (hex colours or `none`; no `currentColor`, CSS, gradients, `use`, scripts
  or external references). Overlaps are layered opaque shapes rather than holes, so the
  result does not depend on the fill rule. The whole folder stays under 400 KB.
- **Palette:** ink `#1F3A5F`, light `#CFE0F3`, white, red `#D9534F`, yellow `#F2C14E`,
  green `#5BAA6E`, plus a few tints.
